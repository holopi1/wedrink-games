# Слова недели для игр WeDrink

Слова на кассе меняются раз в неделю. Файл `words.json` руками не правим: слова в нём закодированы, их собирает утилита `encode_words.py`. Игры пересобирать не нужно.

**Честно: это не защита, а усложнение.** Ключ лежит в коде игр, и любой, кто откроет инструменты разработчика, раскодирует слова. Кодирование нужно только затем, чтобы слова нельзя было прочитать открытым текстом из `config/words.json`, не играя. Настоящее слово считается секретом касс и точки, а не файла.

## Как поменять слова
1. Сделай простой файл `words_in.json` (UTF-8, вне репозитория), например:
   ```json
   {"week": "2026-11-23", "prototype": false,
    "topping": ["слово-вс", "слово-пн", "слово-вт", "слово-ср", "слово-чт", "слово-пт", "слово-сб"],
    "drink":   ["слово-вс", "слово-пн", "слово-вт", "слово-ср", "слово-чт", "слово-пт", "слово-сб"]}
   ```
   - `topping` — слова для топпинга (290-299 очков, скидка 40 ₽ на напиток), `drink` — слова для напитка (300 очков, напиток до 250 ₽ за наш счёт).
   - В каждом массиве ровно 7 непустых слов, не длиннее 40 знаков, без знаков `<` и `>`. Индекс = день недели как в JavaScript: 0 воскресенье, 1 понедельник, ... 6 суббота.
   - `"prototype": true` показывает на экранах метку «прототип». Когда слова настоящие, ставь `false`.
2. Собери файл: `python encode_words.py encode words_in.json words.json` (утилита сама делает обратную проверку).
3. Положи результат в `config/words.json` (формат v7: поля `t` и `d`, плюс `week`, `prototype`, `note`).
4. Проверь: `python encode_words.py check config/words.json words_in.json` — слова раскодируются и совпадают с исходными.
5. Игра берёт файл при каждой загрузке страницы (в адрес добавляется номер дня, так что кэш браузера не мешает дольше суток).

## Как игры читают файл
- Слово раскодируется только в момент показа экрана приза, только для текущего дня и выигранного вида приза. Раскодированные слова не хранятся в глобальных переменных и не пишутся в хранилище.
- Старый формат (массивы `topping` и `drink` открытым текстом) игры тоже понимают, как запасной.
- Если файл недоступен или в нём ошибка (не 7 слов, битый JSON, неверная кодировка), игры молча используют слова-заглушки, зашитые в код.
- Открытие игры с диска (`file://`) читает только встроенные слова: файл подтягивается лишь при открытии через сайт или локальный сервер.
