# Слова недели для игр WeDrink

Слова на кассе меняются раз в неделю правкой одного файла `words.json`. Игры пересобирать не нужно.

1. Открой `config/words.json` и поменяй дату в поле `week` (для себя, игры её не читают).
2. В массиве `topping` — слова для топпинга (290-299 очков), в массиве `drink` — слова для напитка (300 очков).
3. В каждом массиве ровно 7 непустых строк. Индекс = день недели как в JavaScript: 0 воскресенье, 1 понедельник, 2 вторник, 3 среда, 4 четверг, 5 пятница, 6 суббота.
4. Поле `"prototype": true` показывает на экранах метку «прототип». Когда слова настоящие, поставь `"prototype": false` — метка исчезнет.
5. Сохрани файл в UTF-8 без BOM. Игра берёт файл при каждой загрузке страницы (в адрес добавляется номер дня, так что кэш браузера не мешает дольше суток).
6. Если файл недоступен или в нём ошибка (не 7 слов, пустая строка, битый JSON), игры молча используют слова, зашитые в код (заглушки).
7. Открытие игры с диска (file://) читает только встроенные слова: файл подтягивается лишь при открытии через сайт или локальный сервер.
8. Проверка перед сдачей: `python -c "import json; json.load(open(r'words.json', encoding='utf-8'))"`.
